# 汽车笔记

购车、用车、保养相关记录与经验整理。

## 选车参考

| 维度 | 关注点 |
|------|--------|
| 用途 | 日常通勤 / 家庭出行 / 越野 |
| 动力 | 燃油 / 混动 / 纯电 |
| 空间 | 轴距、后备箱容积、后排舒适度 |
| 预算 | 落地价（含购置税、保险、上牌） |
| 保值 | 3年/5年保值率参考 |

## 保养周期速查

| 项目 | 周期 | 备注 |
|------|------|------|
| 机油机滤 | 5000-10000km | 全合成可延长 |
| 空调滤芯 | 10000km | 雾霾/粉尘区缩短 |
| 刹车油 | 2年/40000km | 含水量超3%必换 |
| 变速箱油 | 60000km | CVT/双离合建议提前 |
| 轮胎 | 4-6年/60000km | 磨损标记+年份双判断 |
| 防冻液 | 2-3年 | 冰点检测 |

## 用车小技巧

- **胎压**：每月检查一次，季节温差大时调整
- **电瓶**：超过3年注意亏电，长期停放断负极
- **雨刮**：一年一换，玻璃水别用自来水
- **空调**：每年入夏前清洗一次蒸发箱
